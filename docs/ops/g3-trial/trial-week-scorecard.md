## 填写纪律

- 每个需求逐项答三问并打分，当日记，禁止攒到周末。
- 三问只允许用**摘要视图**作答（Web 看板/深潜，或 CLI `view` 的 summary 输出）——不展开事件流、不读原始输出、不额外问 agent。答不出如实记"无法回答"+ 卡在哪。
- N >= 5。
