# 项目侧可选约定

本文件是**项目/本机侧的具体化**，非协议必需。外部项目没有这些约定时按 SKILL.md「工作区就绪」的降级路径继续。

## 环境卡

项目根的 `AGENTS.md` 里放一节「环境卡」，形状见 <skill_dir>/templates/env-card.md。它是给下一个 worker 的入口摘要，不写决策历史、不抄需求全文。

## 产物落点

- 产物属于当前项目（代码 / 文档 / 用例）-> 落环境卡的「产物落点」。
- 跨项目产物（调研、工具、给别的产品做的交付物）-> 落它所属的仓库；**禁在当前项目新建目录收纳**。
- 落点判断顺序：先看宿主环境有哪些分区与既有项目（先 `ls`），找同类产物的既存落点；能装下就用它 + `decision` 登记（选哪 / 为什么）。

## 本机分区示例（作者环境，按实际替换）

- `~/test`：自研项目与试验（新东西先在这里试）。
- `~/projects`：线上工程与知识 bundle。
- `~/src`：开源镜像与第三方源码。

## 临时目录政策（本机）

本机 `/tmp` 有磁盘配额且长期紧张，临时产物一律落**批次产物目录**（在项目外的固定位置，按批次命名），并保证最终交付物有一份在永久位置。清目录时不会误删证据。

## 跨项目契约

项目之间共享的端口 / topic / Redis key / API 契约，改动后要同步对方的索引文档；只在代码里改会留下看不见的漂移。
