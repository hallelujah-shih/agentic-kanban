# 环境卡模板（推荐形态，非硬依赖）

复制到项目根的 `AGENTS.md` 里，逐项填实。它是下一个 worker 的入口摘要：写「在哪、往哪放、怎么连、不能碰什么」，不写决策历史、不抄需求全文。

```
## 环境卡

- workspace: <项目根>；产物落点: <永久产物目录>；临时产物: <批次产物目录约定>
- context: <知识入口：docs/ 索引、bundle 索引、需求全文源头>
- skills: <本环境可用的领域 skill；常见任务类型 -> 必需 skill>
- tools/mcp: <user 级常驻 MCP（kanban 等）+ 本项目 MCP（配置位置 / 凭据位置 / 动作面）>
- reach: 操作面 <ssh / 部署入口>；测试 <命令入口>；观察面 <日志 / 监控 / 只读 DB>
- 红线: <禁推目标 / 禁触数据 / 禁写生产 / 域红线 / 不做清单>
- ops 教训: <可达路由、flake 签名、既往教训；收尾蒸馏时追加>
```

填写要点：

- **workspace** 写项目根的绝对路径；有多个工作区时写主工作区并注明例外。
- **产物落点** 只列本项目自己的产出；跨项目产物按「先判归属」走，不进本卡。
- **reach** 写可执行的入口（命令 / 地址），不写「见某处」——下一轮 worker 会照着敲。
- **红线** 逐条可判定（「不许推 main」「生产 DB 只读」），不写价值口号。
- **ops 教训** 是本卡随使用增值的部分：每轮收尾蒸馏把可复用的环境事实追加在这里。
